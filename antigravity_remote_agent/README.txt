# Antigravity Remote Control starter instructions

This bundle contains `AGENTS.md`, a project instruction file for your coding agent.

## Use it

1. Create/open a repository folder named `antigravity-remote`.
2. Copy `AGENTS.md` into that repository root.
3. Ask your coding agent to: **“Read AGENTS.md and implement the two project directories and starter files, following the security requirements and acceptance criteria. Start in mock mode; do not claim Antigravity integration works until verified.”**

Target directories:
- `desktop-agent/` — Windows background agent.
- `flutter-mobile/` — Flutter phone app.

A relay service/domain is a separate dependency. The domain alone does not relay messages; a secure relay server or managed tunnel must exist and be configured.
